# 寻时 ATELIER · 透明陀飞轮

独立 Three.js 项目，所有源代码和资源均位于本文件夹。与上一级故宫项目使用不同端口，不会改动其页面。

## 启动

Windows 双击 `启动手表.cmd`，或在本目录运行：

```powershell
npm install
npm run dev
```

访问 http://127.0.0.1:5180 。当前文件夹已安装 Three.js 0.180.0，不需要联网加载模型或字体。需要 Node.js 18 或以上版本。请通过 HTTP 服务打开，不要直接双击 HTML。

## 操作

- **完整腕表**：透明表镜、中壳、后盖、金属表圈、表耳、滚花表冠，以及上下展开的加宽一体式金属表链。表链采用拉丝宽链节、抛光倒角和十字形咬合中节，向末端逐渐收窄。默认及重置视角为十二点朝上的正面视角。左键拖动旋转、右键平移、滚轮缩放；触屏支持手势操作。
- **机械运行**：香槟金传动齿轮、发条盒、蓝钢螺钉、红宝石轴承、镂空桥板、摆轮、游丝和三根走时指针。
- **爆炸视图**：七组组件沿厚度方向连续展开，滑块范围 0–100%；切回整表视图即可复原。
- **组件标注**：点击场景标注、模型或右侧索引，查看组件原理，选择“近距离观察”聚焦。Esc 或详情关闭按钮可取消选择。
- **机械之旅**：自动环绕巡游，再次点击或拖动场景可停止。
- **自由飞行**：W/S 前后、A/D 左右、Q/E 升降，Shift 加速，按住鼠标拖动转向。触屏显示移动按钮。Esc 退出。
- **材质与速度**：透明/金属外壳切换；香槟金、铂银、曜黑三种机芯外观；暂停以及 0.25× / 1× / 5× / 20× 速度。
- **重置与全屏**：场景右侧按钮提供缩放、重置视角和全屏。
- **高清细节**：新增标准 / 高清 / 超清三档画质，界面显示真实渲染像素；高清默认至少 2× 像素倍率，超清最高 3×，并受显存像素预算约束。高分辨率会增加 GPU 负担，可切回标准保证交互速度。
- **机芯微距鉴赏**：一键放大表盘，观察切面指针、时标、开孔桥板、金属轮齿和九圈半游丝。

默认以北京时间联动走时；“减少动态效果”关闭自动镜头过渡。窗口失焦或切到后台会清空飞行按键，后台不累积演示时间，实时时钟回到前台后自动同步。

## 模型范围

XT–02 版参考 [江诗丹顿 Overseas 镂空陀飞轮 6000V/210R-B934](https://www.vacheron-constantin.com/us/en/collections/overseas/6000v-210r-b934.html) 的六瓣表圈、深灰镂空桥板、立体金质指针与六点位陀飞轮。表链参考用户新提供的金色 Overseas 腕表图片，采用加宽、渐窄的十字形咬合链节，并保持上下展开的展示形式。保留 ATELIER 标识，不是品牌官方资产或逐零件工程复刻。原款为金属中壳；本模型为满足内部探索需求保留透明中壳。机芯路线、隐藏结构和精确尺寸由程序近似构建。

42.5 mm 是参考款表壳直径。1× 时陀飞轮框架 60 秒旋转一周，摆轮为 2.5 Hz（每小时 18,000 次半振动）。三根指针共轴，并与轮系共用一个连续时钟。默认按设备系统时间换算为北京时间（UTC+8）；选择速度或暂停即进入机械演示，齿轮、陀飞轮和指针同步加速或暂停。点击“恢复北京时间”返回实时走时。准确度取决于设备系统时钟。

金属拉丝、车削纹理以本地程序生成，不依赖远程图片。文字纹理由 512×128 升级为 2048×512；表镜及大圆柱为 192 分段，小型圆柱为 64 分段，陀飞轮圆环为 192 环向分段。只在有视觉收益的位置细分，并按材质合并静态细节以降低绘制调用。

主轮系采用复合轮轴：80/10 × 75/10 = 60，分轮每小时一圈，四轮每分钟一圈。等比中间轮将两者分别引到中央分针套筒、秒轴；拨针轮系采用 12/48 × 16/48 = 1/12，使时针每 12 小时一圈。每对啮合轮具有相同模数、相切节圆和相反转向，并校准齿相位。蓝色识别点帮助辨认旋转方向。

15 齿擒纵轮以平均 6 秒/圈连续显示，移除了整齿跳步。摆轮和擒纵叉本应往复；高速超出屏幕可分辨频率时显示平均姿态，避免闪烁造成假反转。自动上链摆陀不属于走时轮系，当前保持静止。齿形、游丝弹性、擒纵接触、陀飞轮内部固定轮和发条扭矩仍是简化示意，未实现接触动力学，也不是原厂机芯复刻。

原理参考：[FHH 轮系说明](https://www.hautehorlogerie.org/en/watches-and-culture/watchmaking-knowledge/encyclopedia/train)、[大英博物馆 12/48 与 16/48 拨针轮系记录](https://www.britishmuseum.org/collection/object/H_1958-1201-1586)。

## 构建与验证

```powershell
node scripts/verify-model.mjs
npm run build
npm run preview
```

`dist/` 包含完整本地依赖，可独立发布到静态网站服务器。`preview` 默认同样使用 5180 端口；若开发服务仍在运行，请先停止或设置 `$env:PORT=5181`。

模型构建：`src/watch-model.js`。高精度几何与批处理：`src/watch-geometry.js`。金属工艺纹理及摄影棚反射：`src/watch-finishing.js`。渲染、动画与交互：`src/watch-app.js`。响应式界面：`src/watch.css`。零构建依赖的开发服务：`server.mjs`。

技术参考：[Three.js MeshPhysicalMaterial](https://threejs.org/docs/pages/MeshPhysicalMaterial.html)、[OrbitControls](https://threejs.org/docs/pages/OrbitControls.html)。
